# 《回光》Glimmer at Twilight

2026 TapTap 聚光灯 21 天游戏开发作品《回光》的安装包。

用鼠标整理记忆碎片，按回忆的顺序把它们从起点连到终点。

## 下载

| 系统 | 安装包 | 大小 |
| --- | --- | --- |
| Windows | [GlimmerAtTwilight_windows.zip](GlimmerAtTwilight_windows.zip) | 约 106 MB |
| macOS | [GlimmerAtTwilight-mac.zip](GlimmerAtTwilight-mac.zip) | 约 114 MB |

打开对应文件页面后，点击 **Download** 下载完整压缩包。不要用 Raw，Raw 只会得到很小的 Git LFS 指针文件。

## 安装

### Windows

1. 下载 `GlimmerAtTwilight_windows.zip` 并解压。
2. 保留整个 `GlimmerAtTwilight_windows` 文件夹，不要把 `GlimmerAtTwilight.exe` 单独挪走。
3. 双击 `GlimmerAtTwilight.exe`。
4. 若出现 Windows 安全提示，选择“更多信息”，再选择“仍要运行”。

### macOS

1. 下载 `GlimmerAtTwilight-mac.zip` 并解压，得到 `GlimmerAtTwilight.app`。
2. 第一次打开时，在访达中按住 Control 点 `GlimmerAtTwilight.app`，选择“打开”，并在提示里确认。
3. 若仍被拦截，打开“系统设置 → 隐私与安全性”，允许打开该应用。

## 操作说明

游戏全程使用鼠标。

- 主菜单点击开始。画面暗下后，把鼠标移近逐渐显现的按钮，再点击进入。
- 设置中可以调节亮度和音量。
- **左键拖动**记忆碎片，把它放到合适的位置。
- **右键拖动**旋转碎片。鼠标悬停在碎片上时，也可以用**滚轮**按格旋转。
- 角度和位置接近正确时，碎片会自动吸正并锁住。从起点图钉开始，按画面提示的顺序，一直连到终点图钉。
- **左键轻点**碎片，打开或关闭它的说明。
- **右键快速点一下**碎片，打开放大查看。查看时左键左右拖动可旋转画面，滚轮可缩放，看完点击完成关闭。
- 一条回忆全部连上后，先看完文字，再点击屏幕继续。
- 结局可以选择回到主菜单，或退出游戏。
